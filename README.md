# missmatch

**Misskey おすすめサーバー診断**

マッチングアプリの UI で、あなたに合う日本語 Misskey サーバーと出会えます。

1. **探す（`/`）**: 検索ボックスだけのページ。「病み垢として運用したい」のように書いて送ると、Clef が設定を埋め、候補の説明文と直接突き合わせて並べ替えます。言葉を入れずに条件だけで選ぶこともできます
2. **さがす（`/pick`）**: 初回だけ年齢（2 択）と R-18（3 択）を聞き、あとはスワイプ。 相性の良い順に全面画像のカードで提示。右で ♥、左で ✕、タップで詳細、↶ で戻す。**♥ と ✕ から好みを学び、次の 10 枚を並べ替えます**。質問には答えません
3. **マッチ**: 相性 70% 以上のサーバーに ♥ を送ると「マッチしました！」。いいねしたサーバーはグリッドに残り、本体や misspace の連合グラフへ飛べます。✕ したサーバーは「よくないね」に残り、戻せます
4. **あなた**: 学習した好み（チップで見えて、個別に忘れられる）、登録のしかた（受付中・承認制・招待制・停止中）、絶対条件（メアド不要・広告なし・GTL・本家のみ・最新版）、話題、空気感、規模（個人〜大手）と流速。すべて 1 タップ、該当件数つき。招待制・停止中を含めると候補は約 100 件から約 580 件に広がります

`/pick` の下タブは みすまっち（ホーム）/ さがす / いいね / よくないね / あなた。配色と部品は Misskey、カードと操作は Tinder に倣っています。プロフィールはブラウザにだけ保存されます。

[misspace](https://github.com/hitalin/misspace)（連合グラフの可視化）の姉妹プロジェクトです。
misspace が「情報を見せて自分で選ぶ」ツールなのに対し、missmatch は「こちらから候補を勧める」ツールです。

## 仕組み

```
joinmisskey instances.json ──→ 正規化 (ServerInfo: 登録要件・ドライブ容量・GTL・広告・更新の遅れ・本家/フォーク …)
                                   │ 日本語・登録受付中
GET /api/servers ──→ KV の雰囲気を全件読んで即返す（欠けは応答後に LTL 50 件 → Clef → KV 7 日）
                                   │
                        属性表 (ServerProfile[]) をブラウザへ
                                   │
一言 ──→ POST /api/intent ──→ Clef が設定を読み取り + 97 件との噛み合い確率 ──→ 発見の設定に反映
                                   │
       localStorage の設定と学習した好み ──→ 採点（ブラウザ内）──→ 10 枚ずつスワイプ ──→ ♥/✕ で好みを更新
```

ロジックは `src/lib/` の純粋関数です。`prefs.ts`（発見の設定）、`features.ts`（サーバーの特徴ベクトル）、
`match.ts`（フィルター・採点・スワイプ学習）、`intent.ts`（一言の変換）、`profile.ts`（保存形式）。

### Clef に聞いていること

Clef は文章を生成せず、型付きの質問に確率で答える決定モデルです。1 リクエストで以下をまとめて判定します。

| 軸 | 型 | 内容 |
|---|---|---|
| genre.* | noul × 15 | 雑談 / 日記・ひとりごと / イラスト・漫画 / 小説・文章 / 音楽・歌 / ものづくり / 技術・IT / ゲーム / アニメ・漫画 / 推し活・ファン / VRChat・メタバース / 食べ物・お酒 / 動物・ペット / 愚痴・弱音 / 特定テーマ それぞれが目立つか（実在サーバーのコンセプトから選定。独立に判定するので複数が同時に高くてよい） |
| tone | score | 殺伐 → ドライ → 穏やか → ほのぼの の 4 段階 |
| strictness | score | ルールの厳しさ 3 段階 |
| newcomerFriendly | noul | 初心者が会話に入りやすいか |
| nsfw | noul | 成人向け投稿が目立つか |
| closedCommunity | noul | 身内ノリが強いか |

state にはサーバー名・説明文・ルール・ユーザー数・投稿数/日・最近の投稿 50 件を渡します。

### 採点

- **ハードフィルター**: 日本語サーバー、新規登録受付中（承認制を含む）、18 歳未満には登録年齢を 18 歳以上に制限しているサーバーを出さない
- 好みの適合度は **軸ごとの適合度 (0..1) × 重み** の加重平均。軸は R-18（4）、話題・学習した好み（3）、空気・関わり方（2）、ルール（1.5）
- 検索語があるときは **相性 = 0.75 × 文章との噛み合い + 0.25 × 好みの適合度**。文章が主、好みは従
- 規模・流速・絶対条件はハードフィルター。雰囲気が未判定のサーバーは雰囲気系の適合度を 0.5 で扱う
- 学習した好みは ♥ で +0.3、✕ で −0.15 の割合で特徴ベクトルに寄せ、8 スワイプで最大の重みになる。束（10 枚）を見終わるたびに次の束に反映

## 開発

```sh
pnpm install
pnpm dev        # vite dev（adapter-cloudflare が wrangler.toml のバインディングを再現。AI はリモート実行で課金対象、KV はローカル）
pnpm test       # vitest
pnpm check      # svelte-check
pnpm lint       # biome
pnpm preview    # 本番ビルドを wrangler dev で起動
```

### デプロイ

```sh
wrangler kv namespace create VIBE_KV   # 出力された id を wrangler.toml に書く
wrangler secret put WARM_SECRET        # /api/warm 用
pnpm deploy
```

### 事前計算

初回アクセス時のレイテンシを抑えるため、推薦され得るサーバー（日本語・登録受付中、約 100 件）を活発な順に事前計算できます。
外部の cron（GitHub Actions など）から叩く想定です。

```sh
curl -X POST "https://missmatch.<your>.workers.dev/api/warm?limit=50&offset=0" \
  -H "Authorization: Bearer $WARM_SECRET"
```

## 対象

- [joinmisskey](https://join.misskey.page/) に登録されている、`langs` に `ja` を含むサーバー。既定は新規登録を受け付けている 97 件（2026-10 時点、653 件中）。「登録のしかた」で招待制・停止中を含めると、停止中でも 1 日 1 人以上が読んでいる 480 件が加わります
- ローカル TL を無効にしているサーバーには投稿取得のリクエストをせず、説明文とルールだけで判定します

要件定義と設計判断の根拠は [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) にまとめています。
